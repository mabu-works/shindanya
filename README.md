# 診断メーカー（shindanya）

名前を入力すると診断結果が出る、ブラウザ完結の静的Webサイトです。ビルド不要で、そのまま静的ホスティングに置けば動きます。

🌐 公開先: [shindanya.vercel.app](https://shindanya.vercel.app)
📜 更新履歴: [CHANGELOG.md](CHANGELOG.md)

## 📖 概要

- 名前とテーマを選んで「診断する」を押すと結果が表示されます。
- 結果は「名前＋今日の日付＋テーマ」をシードにした決定的乱数で選ばれるため、同じ名前・同じ日・同じテーマなら何度やっても同じ結果になります。日付が変わると結果も変わります。
- 入力した名前は外部に送信されません（アプリ自体は通信しません。「Xで共有する」を押した場合のみ、共有文面がXに渡ります）。

## ✨ 機能

- 診断テーマ6種（各8結果、タイトル＋2〜3文の説明文付き）
  - あなたを天気に例えると
  - あなたのイメージカラーは（色）
  - あなたを動物に例えると
  - あなたを駅に例えると
  - あなたを食べ物に例えると
  - あなたのRPGジョブは
- テーマはチップUIで切り替え可能
- 結果カードを Canvas（1200×630）で描画し、PNGとしてダウンロード可能
- X共有リンク（intent）で結果テキストを投稿可能
- PWA対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダークモード対応（prefers-color-scheme）

## 📝 使い方

1. 名前を入力します。
2. 診断テーマのチップを選びます（初期状態では「天気」が選ばれています）。
3. 「診断する」を押すと、結果カードに結果のタイトルと説明文が表示されます。名前が空のまま押すとエラーが表示されます（Enterキーでも診断できます）。
4. 結果カードの「結果カードを画像で保存」でPNG画像として保存したり、「Xで共有する」から結果をXに投稿したりできます。

## 🪟 Windows 版

`windows/` フォルダに、同じ仕様の Windows アプリ（.NET 8 / WinForms）があります。診断ロジック（FNV-1aハッシュ＋mulberry32、シードは `名前|日付|テーマID`）と全6テーマ・48件の結果文は Web 版と同一で、同じ名前・同じ日なら Web 版と同じ結果になります。オフラインで使えます。

- ダウンロード: [GitHub Releases（Windows版 v1.0.0）](https://github.com/mabu-works/shindanya/releases/tag/v1.0.0)
- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Shindanya.exe` を生成
- Web 版の「結果カードを画像で保存」「Xで共有する」の代わりに、結果テキストをクリップボードへコピーするボタンを付けています

## 📋 技術メモ

- ビルド不要の静的サイト（素のHTML/CSS/JavaScript、外部リソース不使用）。
- 決定的乱数：FNV-1aハッシュ＋mulberry32。シードは `名前|日付（YYYY-MM-DD）|テーマID` で、テーマごとに8件の結果から1件を選びます。
- 結果カードはCanvas（1200×630）に描画し、PNGとしてダウンロードします。ファイル名は `shindan-<テーマID>-<日付>.png` です。
- Service Worker（`sw.js`）：同一オリジンのGETをキャッシュ（キャッシュ名 `shindanya-v3`、stale-while-revalidate方式）。
- テーマ（ダーク／ライト）は右上のボタンで切り替えでき、選択はlocalStorage（`shindanya-theme`）に保存されます。未保存時の既定はダークです。

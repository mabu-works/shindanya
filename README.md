# 診断メーカー（shindanya）

名前を入力すると診断結果が出る、ブラウザ完結の静的Webサイトです。ビルド不要で、そのまま静的ホスティングに置けば動きます。

## 概要

- 名前とテーマを選んで「診断する」を押すと結果が表示されます。
- 結果は「名前＋今日の日付＋テーマ」をシードにした決定的乱数で選ばれるため、同じ名前・同じ日・同じテーマなら何度やっても同じ結果になります。日付が変わると結果も変わります。
- 入力した名前は外部に送信されません（通信自体が発生しません）。

## 機能

- 診断テーマ6種（各8結果、タイトル＋2〜3文の説明文付き）
  - あなたを天気に例えると
  - あなたのイメージカラーは（色）
  - あなたを動物に例えると
  - あなたを駅に例えると
  - あなたを食べ物に例えると
  - あなたのRPGジョブは
- テーマはチップUIで切り替え可能
- 結果カードを Canvas（1200×630）で描画し、PNGとしてダウンロード可能
- X共有リンク（intent）で結果テキストを投稿可能
- PWA対応（ホーム画面に追加可能、オフラインキャッシュ）
- ダークモード対応（prefers-color-scheme）
